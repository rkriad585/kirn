# `math`

The math module includes source-backed helpers such as `sqrt`, `abs`, `clamp`, `min2`, `max2`, `ipow`, and `fpow`.

```kirn
root = sqrt(16.0);
safe = clamp(root, 0.0, 3.0);
```

Check the module tests for numeric types and edge cases.
