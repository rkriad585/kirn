# Support

Kirn is maintained by RK Riad Khan for the Kirn language organization.
For organization contact, email `thekirnlang@gmail.com` or visit
[kirn-lang.github.io](https://kirn-lang.github.io/).

Please search existing [GitHub issues](https://github.com/rkriad585/kirn/issues)
before opening a new one.

- **Bug reports:** use the [bug report form](https://github.com/rkriad585/kirn/issues/new?template=bug_report.yml) and include `kirn --version`, the operating system, and a minimal reproduction.
- **Feature requests:** use the [feature request form](https://github.com/rkriad585/kirn/issues/new?template=feature_request.yml).
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not disclose vulnerabilities in a public issue.
- **Questions and usage help:** start a GitHub Discussion or include the exact command and diagnostic output in an issue.

Support is community-based and is not a guaranteed response-time service. Please
do not include passwords, access tokens, private source code, or other secrets in
reports.
