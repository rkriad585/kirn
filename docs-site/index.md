## The shape of the docs

Start with **Learn** if you are new to Kirn. Use **Guides** when you are working with the CLI, project files, or build targets. Go to **Reference** when you already know what you are looking for.

> Kirn is actively evolving. These docs describe verified behavior and clearly label work that is still on the roadmap.
