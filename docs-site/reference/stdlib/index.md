# Standard library

The standard library is organized into small modules. The current source tree includes `core`, `io`, `math`, `strings`, `collections`, `json`, `os`, `path`, `regexp`, `time`, and `text/slug`.

Each module is backed by source and test files in the repository. Use the pages in this section as a map, then inspect the module and its tests for the exact current signatures.
